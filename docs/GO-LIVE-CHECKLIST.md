# MPS Version 1.0 Go-Live Checklist

- [ ] CI pipeline is green for the release commit.
- [ ] Container vulnerability scan has no unresolved critical findings.
- [ ] Staging database migration completed successfully.
- [ ] UAT critical cases passed.
- [ ] Performance thresholds were met in the approved environment.
- [ ] Accessibility checks completed for primary workflows.
- [ ] Production secrets and TLS certificates are configured.
- [ ] Full backup completed and restore test evidence approved.
- [ ] Monitoring, alerts, logs and on-call contacts are active.
- [ ] Deployment and rollback owners are present.
- [ ] Release notes and known limitations are approved.
- [ ] Product Owner and Operations record Go decision.
