# MPS Version 1.0 User Acceptance Test Plan

## Participants
- Product Owner
- Organization Administrator representative
- Coordinator representative
- Member representative
- QA Lead

## Entry criteria
- Staging deployment completed.
- All mandatory migrations applied.
- Test users and representative data loaded.
- No unresolved critical security or data-integrity defects.

## Exit criteria
- All critical UAT cases pass.
- No unresolved Critical defects.
- High defects are resolved or formally accepted.
- Backup and restore evidence is approved.
- Product Owner records a go/no-go decision.

Results must be recorded in `UAT-TEST-CASES.csv`; this repository does not claim external UAT execution has occurred.
