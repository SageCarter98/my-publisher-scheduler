# Sprint 1 — Engineering Foundation

## Goals
- Establish the modular monolith repository.
- Provide repeatable local startup through Docker Compose.
- Establish PostgreSQL migrations and core audit fields.
- Define consistent API responses and error handling.
- Add health checks and CI validation.

## Definition of ready for Sprint 2
- Backend compiles and tests pass.
- Web client builds.
- PostgreSQL starts and Flyway applies the foundation migration.
- Health endpoint responds successfully.
- CI configuration is committed.
- Secrets remain external to source control.
